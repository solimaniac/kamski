# Kamski Bench

An offline-first Go batch benchmark of observed two-tool selections and stated
justifications in fictional scenarios. Not a test of consciousness, empathy,
free will or moral agency. Implementation is incremental; see
[the plan](docs/implementation-plan.md) and [architecture](docs/architecture.md).

`go test ./...` requires no API credentials. Raw data and generated HTML are
ignored. Live calls and publication are always explicit.
